# 1. Project Overview

## Introduction
**EcoQuest** is the provisional name for a proposed gamified environmental education platform for school and college students in India. It connects environmental learning with practical actions at school, home, and in the community. The inspected `Smart-Crop-Advisor` repository had no application files.

## Problem statement and discrepancy
The supplied project record is titled **“Smart Crop Advisory System for Small and Marginal Farmers”**, while its description concerns environmental education, student engagement, sustainability tasks, points, and competitions. These are different products. **Official project title and faculty-approved problem statement: NEEDS CONFIRMATION.** Until confirmed, this documentation uses the environmental education description as provisional scope; it does not claim crop advisory functionality.

## Objectives and vision
- Make environmental learning practical, interactive, and connected to local issues.
- Encourage approved activities such as waste segregation and tree planting.
- Give teachers tools to create learning and review activity evidence.
- Track progress and recognize participation through transparent points, badges, challenges, and leaderboards.
- Support safe, accessible use in Indian educational communities.

**Vision:** help educational communities turn environmental awareness into sustained participation. Outcomes must be measured; impact is not presumed.

## Audience and stakeholders
| Group | Interest / responsibility |
|---|---|
| Students | Learn, complete activities, submit evidence, track progress |
| Teachers / eco-club coordinators | Manage authorized learners/content and review submissions |
| Administrators | Manage accounts, schools, content, challenges, and platform oversight |
| Schools and colleges | Adopt and organize participation |
| NGOs / public agencies | Possible content or challenge partners; unconfirmed |
| Faculty / project team | Approve scope, requirements, design, and delivery |

## Expected outcomes and scope
Proposed outcomes are a web platform for lessons, quizzes, sustainable tasks, submissions, progress, and school participation. Provisional MVP: role-aware registration/login; student lessons and quizzes; teacher-managed content/tasks; submission review with optional image evidence; points ledger and personal progress; basic leaderboard; admin management. MVP boundaries, age/consent, moderation, and scoring require approval. Streaks, notifications, localization, and integrations are later candidates.

## Glossary
| Term | Meaning |
|---|---|
| Eco-point | Traceable point for an approved activity or learning result |

| Submission | Student response/evidence for a task |
| Badge | Non-monetary achievement for defined criteria |
| Challenge | Time-bounded activity/competition with eligibility rules |
| RBAC | Role-based access control |
